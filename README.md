Using the Pro Micro Starter Kit
## Project kit brand Inland Pro Micro Starter Kit
### Includes Arduino Main Development Micro Board, USB Micro B connector, 220 Ohm Resistors 1/4 Watt (15), 470 Ohm Resistors 1/4 Watt (5), 10k Ohm Resistors 1/4 Watt (5), F5-Red LED (5), f5-Green LED (5), F5-Blue LED (5), F5-full-colour RGB Transparent And Common Cathode (2), Female to female 20cm Dupont Line (10), Male to male 20cm Dupont Line (10), Male to female 20cm Dupont Line (10), 6*6*5mm Buttons (4), ZY-170 Holes White Breadboard (1), 5516 light resistor5-10k Ohm dark resistor 0.2M Ohm photo resistor (1), IR emmissions 0.5cm wava length 940mm super component (1), and IR receiver VS1838B Super component (1).
### First Need to Install Arduino IDE and Driver 
  ## https://www.arduino.cc/en/software/#1.5.x - link provided by kit user guide (Micro Center)
        ## Installed Arduino IDE 2.3.9_Windows_64bit.exe (Note that the provided QR code link to the user guide was last updated 17MAR2022 and describes an older version of Windows and Arduino IDE; therefore I am using the updated and/or most capatible version for my system as well as the Micro Arduino Board.)
      ###Completed driver installation as described, steps are the same for installation. Then removed Micro Board from packaging and plugged it in. Upon first  plug in an/or power on the red and green LED on the board lit up simutaneously then the red LED went away after a second, leaving the green light on.
